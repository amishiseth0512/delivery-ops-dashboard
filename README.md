# Delivery Management Dashboard

A simple full-stack delivery management application built with **React, TypeScript, and FastAPI**.

## Features
- Integrated REST API endpoints for order and delivery management.
- Implemented JWT authentication and role-based authorization.
- Designed PostgreSQL relationships with order status history tracking.
- Containerized with Docker and deployed on AWS EC2 with PostgreSQL hosted on AWS RDS.

## Tech Stack
React, TypeScript, Python, FastAPI, PostgreSQL, JWT, Docker, AWS EC2, AWS RDS.
